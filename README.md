# Pocket Genesis
Two immortal lives. An endless civilization.

A standalone autonomous pixel civilization for a seven-inch ESP32, intended to outlive its original hardware. No mandatory interaction, internet, subscription, final victory or reset.

Design baseline v0.1; firmware not yet implemented. Owner review and board verification are required before firmware development. Existing repository license is unchanged.
