# Pocket Genesis
Two immortal Pixels. An endless civilization.

**Central design principle: Two identical devices, the same laws, different random seeds — dramatically different civilizations.** We create the laws; inhabitants create their history.

A standalone autonomous pixel civilization for a seven-inch ESP32, intended to outlive its original hardware. No mandatory interaction, internet, subscription, final victory or reset.

Design baseline approved. Portable C++ simulation is in development; actual ESP32 firmware, persistent saves, full civilization mechanics and board verification are not complete. Run host regression tests with `bash scripts/test-host.sh` from the development branch. Existing repository license is unchanged.
