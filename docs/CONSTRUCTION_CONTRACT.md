# Disposable tile construction prototype
State: a bounded array of three structure records, one per initial blueprint (campfire, shelter, food store), each storing tile index, builder ID, progress, start/completion tick, state (empty/building/complete/abandoned). One active project. This is a deliberately small test catalog, not a civilization-wide building limit. One tile per structure; no coordinate expansion. No changes to canonical World or saves.
Rules: founders may propose a structure they personally know how to build, on their present unoccupied tile, if its actual wood/stone stocks cover the blueprint. Stable founder/blueprint order; no random global spawning or scripted unlock time. Initial demand is unmet access to each of the three primitive capabilities. Material cost is deducted once at admission; work takes 20/40/30 eligible idle ticks for campfire/shelter/store. Work only on the original tile, survival and childcare first; pauses if unavailable, resumes after returning, abandons after 600 ticks without work, consumed materials stay consumed. An abandoned site remains recorded in this first prototype; no automatic replacement or free recovery. No building effects yet; a completed shelter is not automatically occupied, a store does not generate food, a campfire does not automatically cook. Later storage, shelter benefits, maintenance, ruins, habitat integration, actual demand and multiple projects need explicit contracts.
Scheduling: reuse existing optional discretionary work hook. Active research gets priority, local teaching or research admission can beat new construction; if a construction project is active, only that project can advance until completed or abandoned. No citizen gains construction work and research/teaching in the same tick. Construction reservation only for eligible local builder, otherwise preserve existing exploration. No forced births, no clock or probability changes. Probe-only, deterministic stable ordering. Default world and verified family/discovery environments unchanged.
Verification: unit tests for prerequisite, resources, single tile occupancy, actual work, survival interruption, no refund, no duplicate admission, completion; separate device probe uses real research and lifecycle from seed42 for 43200 ticks, emits actual construction start/completion/abandonment, discovered counts, population and actual birth count. No official world; no SD/display integration. Later functionality must be tested independently before claiming a deployed civilization capability.
