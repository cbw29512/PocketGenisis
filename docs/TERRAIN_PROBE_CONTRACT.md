# Terrain generation evaluation
Use reviewed upstream FastNoiseLite 1.1.1 (exact pin 7ccfbc16eb1c932568f177d63a9ba51d89bbe516, MIT notices included) rather than recreate gradient noise. Initial isolated host candidate only; 100x60, 3 bytes per cell, 18,000 bytes total, elevation/moisture quantized to bytes and provisional five biome classes. Two-dimensional Perlin with explicit frequencies, domain-separated local seed RNG, no dynamic allocation by the generator and no live stream changes. Full seed influences local stream. Classification lowland/grassland/forest/dryland/highland; lowland is not yet an impassable ocean. No resources, climate, rivers, mining or collision rules changed. Same-seed cell-by-cell repeatability and 16 distinct terrain fingerprints checked; high seed bits test. Compile only this test with signed wrapping arithmetic and FMA contraction disabled; audited Perlin coordinate priming/hash intentionally wrap and signed right shift is implementation-defined, so cross-toolchain equivalence not yet certified. Do not use unused algorithms without review. Target and other compiler fingerprints, actual memory/timing and suitable founder spawn and sustainable resource placement must be verified before official generation. Canonical persistence must store generated integer terrain and generation version rather than assume floating-point equivalence. No official world or Tab5 changes.
