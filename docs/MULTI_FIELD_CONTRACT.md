# Disposable multiple-field increment
PG_MULTI_FIELD_PROBE adds three extra field sites (four total) after the housing slots. All reuse existing field blueprint, occupancy, work and crop primitives. Extra field requires one completed field, living count greater than four per completed field (provisional planning approximation), local food <=48, existing field viability and materials. Separate crop state for each site, no duplication of planting/harvest logic. One discretionary farm task globally per tick, nearest ready field within existing radius, stable slot ties; no new RNG or population cap. Between jobs, use nearest viable growing field and existing home fallback. Wild food renewal suppressed only on completed cultivated tiles. Single existing irrigation channel selects its driest adjacent completed field below threshold, stable field order ties, same two-unit rate/source reserve/accounting. No increase in rate merely because multiple fields exist. No multiple channels, permanent profession assignment, permanent farm limit, or canonical save changes. Earlier profiles retain their layout and rules. Controlled tests exercise construction demand and costs, independent crops, renewal mask, irrigation selection, and nearest task. Unforced one-year smoke reports actual outcomes; may not reach multi-field demand. Separate Elecrow profile. Baseline irrigation CI was still running when increment was prepared; combined CI must pass before extending further.
