# Optional continuous livestream — proposed
Broadcast the same authoritative world that lives on the ESP32. Start with an external camera pointed at the physical display (no firmware changes). Later publish read-only versioned render snapshots and events over optional local network to a separate computer. The computer renders a larger stream scene and uses broadcast software; ESP32 never performs video encoding or holds platform credentials. No second independent simulation and no public access to device. 
Suggested overlay: world age, population, season, current technology, recent discoveries, founder profiles and historical milestones. A future public viewer can inspect citizen biographies and genealogy from sanitized read-only replicated data. No viewer commands, donations or chat can change simulation in the baseline. 
Acceptance: stream disconnected/reconnected without world pause, tick divergence or save corruption; bounded memory and queue with drop/coalesce stale frames; no secrets in logs; broadcaster labels offline/stale snapshots; compare stream world ID and tick with device. Public streaming optional, not required for MVP. Verify current platform requirements and costs before choosing platform.
